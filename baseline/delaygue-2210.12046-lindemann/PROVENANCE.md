## Exact source statement

Delaygue states Theorem C as:

> **Theorem C (Lindemann–Weierstrass).**
> If `alpha_1,...,alpha_n` are distinct algebraic numbers, then
> `e^{alpha_1},...,e^{alpha_n}` are linearly independent over `Qbar`.

The source also states the equivalent algebraic-independence formulation for
`Q`-linearly independent algebraic exponents. The theorem package uses only
the distinct-exponent linear-independence form quoted above.
