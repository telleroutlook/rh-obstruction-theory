# Limitations — Theorem G (G-fredholm-certificate)

**Theorem ID:** G-fredholm-certificate

---

## What Theorem G does NOT prove or claim

1. **Does not prove RH or imply anything about the truth of RH.**  
   The obstruction is independent of whether RH holds — it is a statement about
   what the observation map O_θ can distinguish, not about whether Riemann zeros
   are on the critical line.

2. **Does not assert the kappa_toeplitz construction (or any specific P ∈ 𝔐_FC) is
   definitively blocked from being repaired.**  
   A method could step outside 𝔐_FC by incorporating the S(T) data (via a non-zero-free
   route), producing a CORE-4 closure path that is outside this theorem's scope.

3. **Does not assert that no Fredholm certificate exists.**  
   The theorem is about the theta-level observation class 𝔐_FC only. A certificate
   outside this class (e.g., constructed via a non-spectral identity or from a future
   zero-free S(T) computation) is not excluded.

4. **Does not classify whether S(T) is genuinely uncomputable from primes.**  
   That claim (G-hard) is an explicit CONJECTURE and is never used as a proof premise.
   It represents the open mathematical frontier (the P4 problem of the sibling repo).

5. **Does not produce a barrier in the full program §3.3 sense for all Fredholm methods.**  
   The method class 𝔐_FC is restricted to theta-level observation. A broader Fredholm
   certificate method class (allowing any zero-free arithmetic source) is not covered.

6. **G-info is PROOF-DRAFT, not INDEPENDENTLY-CHECKED.**  
   The explicit perturbed-zero exhibit in Prop. G.3 is structurally parallel to E-neg §3
   but has not been independently checked or formalized.

7. **Non-vacuity is PROOF-DRAFT (Bochner positivity).**  
   The kappa_toeplitz construction's Bochner positivity argument (sibling repo) is a
   PROOF-DRAFT. If it fails, the non-vacuity witness would need to be replaced by
   a different P ∈ 𝔐_FC.

8. **This is NOT a negative result about all possible proofs of RH.**  
   It is a precise, scoped obstruction for one method class under one observation map.
