# Checker — Theorem K

The analytic theorem is not certified by computation.
`inert_prime_instance_check.py` replays exact rational Chebyshev values and
`p`-adic valuations for `p=3`, `u_0=i/3`. It also checks on-line conductor
`p`-integrality and an adversarial mutation that removes the inert denominator.
