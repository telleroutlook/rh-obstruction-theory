# Limitations — Theorem H (H-information-hierarchy)

1. **Theorem H is a unification framework, not new mathematics.** Its content is
   exactly the union of B2 and G; all mathematical claims reduce to those theorems.

2. **Theorem H' incomparability is NOT established (Gate-A BLOCKED, OB-32).** The earlier
   "`O_finite ⊊ O_theta`" total chain (and then the OB-27 "incomparable partial order") are
   both superseded. Under Theorem G's **literal** `O_theta(𝒵)=d_n=θ_level(n)` — a fixed,
   `𝒵`-independent, hence **constant** map — `O_theta` refines every map, so `O_theta ≺
   O_finite` (comparable, strictly coarser); only the one direction `O_finite ⋠ O_theta` is
   CONFIRMED (same-Im pair, `Li_1` branch). Genuine incomparability would need a **nonconstant**
   `O_theta` (e.g. sampled counts `N_𝒵(d_m)`) plus an **exact** same-`O_finite`/different-`O_theta`
   witness — the "`ker DF`" sketch is only first-order, so neither is provided. Also: `O_oracle`
   must be the **full multiset 𝒵** (ordinates-only fails `O_finite ≼ O_oracle`, by the same-Im
   witness), and the structure is a refinement **preorder**, not a lattice.

3. **The O_vM layer is not a well-defined map on `𝔛_sym` (OB-32).** `Λ(n)` is `𝒵`-independent;
   and for the actual ζ, the full `Λ(n)` determines `−ζ'/ζ`, hence ζ and its zeros — so the
   "G-hard dichotomy" is not well-posed as stated (it would need a restricted/truncated `O_vM`).

4. **Does not close any escape route.** The O_oracle layer is explicitly the escape —
   a method with access to all zero locations trivially avoids all obstructions.

5. **Does not prove or imply RH.**
