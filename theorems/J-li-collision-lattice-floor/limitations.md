# Limitations — Theorem J

1. This is a per-construction theorem. It gives no uniform lower bound as the
   on-line node set and off-line orbit vary.

2. `q_min` may equal `1`, in which case the height floor is vacuous.

3. The bound controls the off-line coefficient `q` (and hence the sup-norm of
   the relation), but it does not separately bound every on-line coefficient.

4. The theorem is finite integer linear algebra. It uses no analytic zero-set
   information and makes no claim about RH.

5. The application to Li observations requires rational observation values and
   full rank after denominator clearing. Those conditions must be checked for
   each construction.
