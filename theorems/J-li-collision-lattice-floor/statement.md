# Statement — Theorem J (Li-collision lattice floor)

**Theorem ID:** J-li-collision-lattice-floor  
**Mathematical status:** PROOF-DRAFT (prepared for Gate-A review)

## §1. Abstract integer-relation form

Let `m,K ≥ 1`. Fix an integer matrix

```
A = [a_1 ... a_K] ∈ Z^{m×K}
```

with rank `m`, and a vector `d ∈ Z^m` such that the augmented matrix
`[A|d]` also has rank `m`. Let

```
L = A Z^K ⊂ Z^m.
```

Define

```
q_min = [L + Zd : L],
```

the index of `L` in the lattice generated by `L` and `d`.

## §2. Theorem

**Theorem J.**

1. The set
   ```
   { q ∈ Z : qd ∈ L }
   ```
   is `q_min Z`. In particular, `q_min` is a positive integer.

2. Every integer relation
   ```
   A c + q d = 0,       c=(c_1,...,c_K) ∈ Z^K, q ∈ Z,
   ```
   has `q ∈ q_min Z`, hence `|q| ≥ q_min`.

3. If `D_m(B)` denotes the greatest common divisor of all `m×m` minors of an
   integer matrix `B` of rank `m`, then
   ```
   q_min = D_m(A) / D_m([A|d]).
   ```

4. Consequently, for every nonzero relation with `q ≠ 0`,
   ```
   max(|q|, |c_1|,...,|c_K|) ≥ q_min.
   ```

## §3. Application to rational finite Li observations

Suppose rational on-line nodes and one rational off-line orbit give rational
observation vectors `v_1,...,v_K,d_R ∈ Q^m`. Choose a positive integer `R`
clearing all denominators and put

```
A = [Rv_1 ... Rv_K],   d = Rd_R.
```

If `A` and `[A|d]` both have rank `m`, Theorem J gives the exact off-line
multiplicity divisor and the height floor for every integer observation
collision using those nodes.

This application is independent of the overall factor chosen in the Li
observation convention: multiplying every observation by the same nonzero
integer only changes the common denominator-clearing factor, not `q_min`.

## §4. Non-claim

Theorem J does **not** prove a uniform lower bound over all rational node sets
and off-line orbits. It is possible that `q_min=1`. Full Open Problem 1 asks
for a super-polynomial lower bound for the infimum of `q_min(m)` over the
admissible constructions; that remains open.
