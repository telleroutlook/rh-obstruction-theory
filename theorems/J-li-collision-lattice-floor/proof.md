# Proof — Theorem J

**Status:** PROOF-DRAFT. The argument is finite integer linear algebra and uses
no analytic input.

## §1. The annihilator is a principal ideal

Let `G=(L+Zd)/L`. Since `L` has finite index in `Z^m` and `L+Zd` is also a
lattice in `Z^m`, `G` is finite. It is generated by the coset `d+L`, hence is
cyclic. Let its order be `q_min`. Then

```
q(d+L)=L  ⟺ qd∈L
```

holds exactly when `q_min | q`. Thus
`{q∈Z:qd∈L}=q_min Z`.

## §2. Relations force divisibility

If `Ac+qd=0`, then `qd=-Ac∈L`. By §1, `q_min|q`. Therefore `|q|≥q_min`
whenever `q≠0`. The height inequality follows immediately from
`max(|q|,|c_1|,...,|c_K|)≥|q|`.

## §3. Determinantal-divisor formula

For an integer matrix `B` of rank `m`, the lattice `BZ^r` has index

```
[Z^m : BZ^r] = D_m(B)
```

in `Z^m`; this is the Smith-normal-form/determinantal-divisor theorem. Applying
this to `[A|d]` and to the sublattice `AZ^K` gives

```
q_min
  = [L+Zd : L]
  = [Z^m : L] / [Z^m : L+Zd]
  = D_m(A) / D_m([A|d]).
```

Both numerator and denominator are positive because both matrices have rank
`m`. No discovery-tier computation is used.
